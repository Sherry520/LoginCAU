# LoginCAU - 校园网登录脚本

这是一个用于自动登录校园网的 *Python* 脚本，支持通过命令行输入账号和密码，并自动**检测**网络状态、**登录**状态以及**注销**功能。脚本设计简洁，易于使用，同时注重安全性。

___

## 功能

1. **自动获取认证网关地址**：
   - 自动检测并获取校园网认证网关地址。

2. **登录校园网**：
   - 支持输入校园网账号和密码，自动发送登录请求。

3. **注销功能**：
   - 支持手动注销当前登录的账号。

4. **登录状态检测**：
   - 自动检测当前是否已登录校园网。

5. **凭据存储**：
   - 使用系统密钥库（如 Linux 的 `Secret Service` 或 macOS 的 `Keychain`）安全存储账号和密码。

## 特点

- **Python 3 兼容**：基于 Python 3 开发，兼容主流操作系统（Linux、macOS、Windows）。
- **安全性**：
  - 使用系统密钥库存储账号和密码，避免明文存储。
  - 密码输入无回显，防止密码泄露。
- **自动化**：自动检测网络状态和登录状态，减少手动操作。
- **用户友好**：提供清晰的提示信息，支持默认选项和错误处理。

## 安全性

- **密码存储**：账号和密码通过系统密钥库加密存储，避免明文存储的风险。
- **密码输入**：使用 `getpass` 模块输入密码，输入时无回显，防止密码泄露。
- **HTTPS 支持**：如果认证网关支持 HTTPS，脚本会自动使用 HTTPS 进行通信。

## 使用说明

### 1. 安装依赖

确保已安装 Python 3 和 `keyring`、`rquests` 库。可以通过以下命令安装依赖：

```bash
pip install keyring requests
```

### 2. 运行脚本

克隆项目，然后运行：

```bash
git clone https://github.com/Sherry520/LoginCAU.git
cd LoginCAU
python LoginCAU.py
```

### 3. 首次使用

首次运行时，脚本会提示输入校园网账号和密码，并将其存储到系统密钥库中。

### 4. 登录

脚本会自动检测网络状态并尝试登录。如果登录成功，会提示“登录成功”。

### 5. 注销

如果检测到已登录，脚本会提示是否注销。输入 y 或 yes 即可注销。

### 6. 更新凭据

如果需要更新账号或密码，可以直接重新运行脚本，输入新的凭据。
